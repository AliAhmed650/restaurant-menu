# منصة المنيو الرقمي للمطعم

منيو رقمي لمطعم (عربي / إنجليزي) + داشبورد إدارة: المنتجات، التصنيفات، الإضافات، العروض، الطلبات، بيانات المطعم، تخصيص الشكل، وكود QR.

## التشغيل على VS Code (يظهر لايف)
1. افتح الفولدر في VS Code (`File > Open Folder`).
2. ثبّت إضافة **Live Server** (VS Code هيقترحها تلقائيًا).
3. كليك يمين على `index.html` ثم **Open with Live Server** (أو زر **Go Live** تحت).
4. الصفحة بتفتح على `http://127.0.0.1:5500` وبتتحدّث تلقائيًا مع كل حفظ.

بدون إضافة: افتح التيرمنال واكتب `npm start`.

## الدخول للداشبورد
افتح `#admin` (أو زر الدرع أعلى المنيو). البريد `admin@restaurant.demo` وكلمة المرور `admin123`.
الحماية دي تجريبية على مستوى المتصفح. غيّرها قبل أي استخدام حقيقي.

## ملاحظات
- البيانات بتتحفظ في `localStorage` للمتصفح. التعديلات بتظهر فورًا في تبويبات نفس المتصفح.
- لازم إنترنت عشان الخطوط ومكتبة الـ QR (بتتحمّل من CDN).
- لمزامنة حقيقية بين الأجهزة اربطه بقاعدة بيانات (Supabase / Firebase).

## النشر على GitHub Pages
بعد الرفع: Settings ← Pages ← Source: `main` / root. الرابط هيبقى `https://AliAhmed650.github.io/<اسم-الريبو>/`.
